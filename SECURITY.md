# Security Policy

## Reporting a vulnerability

Please do **not** open a public issue for a security problem. Report it privately through
GitHub's private vulnerability reporting:

<https://github.com/NurPech/hannah/security/advisories/new>

Only you and the maintainer can see the report.

## No warranty

Hannah is a private project of a single person. It is provided as is, without warranty and
without any obligation to provide support, updates or fixes. Reports are welcome and will be
looked at, but there are no response time commitments.

## Security model

What you trust at which point, what stays local, which components connect where, and what
is deliberately not protected is described in the documentation (in German):

<https://hannah-docs.leonie.network/manual/security/>
